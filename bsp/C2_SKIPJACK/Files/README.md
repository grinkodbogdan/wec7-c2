# Files — Image Build Configuration

**Milestone:** M2/M3. Will hold WEC7 image config (`platform.bib`, `platform.reg`,
`platform.dat`, `platform.db`, `config.bib`) that define memory layout, registry, and
file-system contents for the OS image. These are authored inside the Platform Builder
workspace (M2). The memory sections of `config.bib`/`platform.bib` must match
`docs/01-hardware-map.md` §2 exactly (Rule 8). Empty until M2.
